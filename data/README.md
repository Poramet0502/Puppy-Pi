# ข้อมูลผลการทดลอง

ไฟล์ CSV ในโฟลเดอร์นี้ส่งออก (export) จากเว็บแอปบนหุ่นยนต์โดยตรง ไม่ได้แก้ไขค่าใด ๆ ทุกไฟล์เป็น UTF-8 มี BOM จึงเปิดใน Excel แล้วแสดงภาษาไทยได้ถูกต้อง ค่าที่รายงานในบทที่ 4 ของเล่มคำนวณจากไฟล์เหล่านี้แยกตามระยะ ใช้ S.D. แบบหารด้วย n − 1

| ไฟล์ | การทดลอง | จำนวน |
|---|---|---|
| `exp1_distance_test_300.csv` | การทดลองที่ 1 ความแม่นยำของระยะทาง | 300 ครั้ง (ระยะละ 100) |
| `exp2_aiming_test_300.csv` | การทดลองที่ 2 ความแม่นยำของการชี้เป้า | 300 ครั้ง (ระยะละ 100) |
| `exp3_walk_test_60.csv` | การทดลองที่ 3 ผลของฐานเล็งเป้าต่อการเดิน | 60 ครั้ง (เงื่อนไขละ 30) |

## การทดลองที่ 1 — `exp1_distance_test_300.csv`

เก็บผลวันที่ 21 ต.ค. 2569 หุ่นยนต์และแผ่นเป้าอยู่ที่ตำแหน่งเดิมตลอดแต่ละระยะ

| คอลัมน์ | ความหมาย |
|---|---|
| `real_distance_cm` | ระยะจริงจากเลนส์กล้องถึงหน้าแผ่นเป้า วัดด้วยตลับเมตร (ซม.) |
| `computed_distance_cm` | ระยะที่ระบบคำนวณได้จาก D = f·W/P (ซม.) |
| `error_cm` | ระยะที่คำนวณได้ − ระยะจริง (ซม.) |
| `error_pct` | `error_cm` / ระยะจริง × 100 มีเครื่องหมาย (บวก = คำนวณได้ไกลกว่าจริง) |
| `note`, `timestamp` | หมายเหตุ และเวลาที่บันทึก |

## การทดลองที่ 2 — `exp2_aiming_test_300.csv`

- 100 และ 150 ซม.: วันที่ 22 ต.ค. 2569 เวลา 20:31–21:33 น.
- 200 ซม.: วันที่ 23 ต.ค. 2569 เวลา 00:14–00:41 น. เป็น 100 ครั้งแรกจากทั้งหมด 107 ครั้งในรอบนั้น

| คอลัมน์ | ความหมาย |
|---|---|
| `distance_cm` | ระยะจริง (ซม.) |
| `status` | `ok` = อ่านตำแหน่งจุดเลเซอร์บนแผ่นเป้าได้, `off_target` = จุดเลเซอร์อยู่นอกแผ่นเป้า, `not_detected` = ระบบตรวจไม่พบเป้า |
| `dx_cm`, `dy_cm` | ตำแหน่งจุดเลเซอร์เทียบกับกึ่งกลางเป้า อ่านจากช่องตาราง 5 มม. (ขวา/บน = บวก) |
| `E_cm` | ความคลาดเคลื่อนของการชี้เป้า E = √(Δx² + Δy²) |
| `hit` | `True` = เข้าเป้า (E ≤ 4 ซม.), `False` = ไม่เข้าเป้า |
| `note`, `timestamp` | หมายเหตุ และเวลาที่บันทึก |

## การทดลองที่ 3 — `exp3_walk_test_60.csv`

เก็บผลวันที่ 28 ต.ค. 2569 บนพื้นไม้ ทำเงื่อนไขไม่มีฐานเล็งเป้าครบ 30 ครั้งก่อน แล้วจึงติดตั้งฐานเล็งเป้าและทำอีก 30 ครั้ง

| คอลัมน์ | ความหมาย |
|---|---|
| `condition` | `without_mount` = ไม่มีฐานเล็งเป้า, `with_mount` = มีฐานเล็งเป้า |
| `walk_mode` | `autogait` = คำสั่งเดินแบบปรับจังหวะก้าวอัตโนมัติของผู้ผลิต |
| `speed_cms`, `duration_s` | ความเร็วที่สั่ง (ซม./วินาที) และเวลาเดิน (วินาที) |
| `cmd_distance_cm` | ระยะที่สั่ง = ความเร็ว × เวลา (ซม.) |
| `actual_distance_cm` | ระยะที่เดินได้จริงตามแนวเส้น วัดด้วยตลับเมตร (ซม.) |
| `error_cm`, `error_pct` | ระยะที่เดินได้จริง − ระยะที่สั่ง (ซม. และร้อยละ) |
| `lateral_cm` | ระยะเบี่ยงตั้งฉากจากแนวเส้น (ขวา = บวก, ซม.) |
| `fell` | หุ่นยนต์ล้มหรือเสียสมดุลหรือไม่ |
| `completed` | เดินครบเวลาที่สั่งหรือไม่ |
| `battery_pct_start` | ร้อยละแบตเตอรี่ก่อนเริ่ม ประมาณแบบเส้นตรงจากแรงดัน 6.4 V = 0% ถึง 8.4 V = 100% (ไม่ใช่ค่าจากผู้ผลิต) |
| `note`, `walk_time`, `timestamp` | หมายเหตุ, เวลาที่เดิน และเวลาที่บันทึก |
